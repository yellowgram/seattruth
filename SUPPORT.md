# Support

SeatTruth is MIT-licensed open source. There is no paid support, no support contract, and no response-time promise. Best-effort help is via GitHub Issues on https://github.com/yellowgram/seattruth or English email to hello@yellowgram.dev.

## In bounds

- How to run the documented dry-run and the documented live path.
- How to read a finding, an ambiguous count, or a run error.
- A defect where SeatTruth breaks a rule in [docs/RULES.md](docs/RULES.md).

## Out of bounds

- Changing the operator's webhook, editing `is_pro`, or writing SQL.
- Advice to refund an end customer. The kit does not recommend end-customer refunds.
- Keys or customer rows in an Issue. Never paste them.
- Joining the operator's Slack, or a collaborator seat used to patch production data.
